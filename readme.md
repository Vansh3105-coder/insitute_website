# 🎓 Coaching Institute Website

A modern, responsive and interactive website designed for a coaching institute.

The project focuses on creating a professional online presence for a coaching institute with a clean UI, smooth animations and responsive layouts across different screen sizes.

## ✨ Features

* 📱 Fully responsive design
* 🎨 Modern and professional UI
* ✨ Smooth scroll animations
* 🔄 Elements animate in and out while scrolling
* 🧭 Navigation bar with smooth scrolling
* 📚 Coaching institute information sections
* 📞 Contact/inquiry section
* ⚡ Lightweight frontend implementation
* 💻 Works across desktop, tablet and mobile screens

## 🛠️ Technologies Used

* **HTML5** — Website structure
* **CSS3** — Styling, layouts, animations and responsiveness
* **JavaScript** — Interactions and scroll-based animations

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/Vansh3105-coder/coaching-institute-website.git
```

Open the project folder and launch `index.html` in your browser.

No additional frameworks or dependencies are required.

## 🎯 Project Goal

This project was created as a real-world frontend website project rather than just a coding exercise.

The goal was to design a website that could be customized and deployed for an actual coaching institute.
